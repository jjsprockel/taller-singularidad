# Taller 8 Preparación de datos y análisis exploratorio

## Justificación

Convertir datos autorizados en un conjunto analítico documentado, sin ocultar decisiones de limpieza ni problemas de calidad.

## Resultados de aprendizaje

- Diseñar una estructura de datos coherente con la unidad de análisis.
- Aplicar controles de completitud, validez, consistencia y duplicación.
- Usar IA o herramientas de computador para apoyar limpieza y exploración.
- Generar un informe de calidad y un conjunto analítico versionado.

## Contexto teórico

- Datos tabulares, texto, imágenes y señales; formatos y metadatos.
- Datos faltantes, valores atípicos, duplicados, codificación y transformaciones.
- Análisis exploratorio guiado por la pregunta.
- Separación entre datos originales, datos procesados, código o instrucciones y resultados.

## Preparación

- Usar datos sintéticos, públicos o debidamente autorizados.
- Traer el diccionario de variables.
- Definir reglas de calidad antes de inspeccionar resultados.

## Actividad paso a paso

1. Crear una copia inmutable del conjunto original y asignar versión.
2. Comprobar estructura, tipos, rangos, duplicados y faltantes.
3. Pedir a la IA propuestas de limpieza y evaluar su efecto antes de aplicarlas.
4. Registrar cada transformación con motivo, regla y número de registros afectados.
5. Generar estadísticas y visualizaciones alineadas con los objetivos.
6. Producir un informe de calidad con problemas resueltos, pendientes y decisiones.

## Aplicación al proyecto

El estudiante debe aplicar la actividad al proyecto asignado y señalar con precisión qué parte elaboró de forma individual. Si el proyecto aún no dispone de datos o autorización, utilizará datos sintéticos, públicos o un caso de práctica. La entrega debe incluir la versión anterior, la nueva versión y una nota breve sobre las decisiones tomadas con apoyo de IA.

## Entregables

- Diccionario actualizado
- Registro de transformaciones
- Conjunto analítico versionado
- Informe de calidad
- Exploración inicial

## Lista de chequeo y KPI

- [ ] Los datos originales permanecen sin modificación.
- [ ] Cada transformación es reproducible.
- [ ] Se cuantifican faltantes y duplicados.
- [ ] Las visualizaciones responden a una pregunta definida.
- [ ] No se interpretan asociaciones exploratorias como causalidad.

**Criterio de avance:** completar al menos 80 por ciento de la lista, sin incumplimientos de privacidad, referencias inventadas o pérdida de trazabilidad.

## Retroalimentación semanal

Revisión de un cambio de datos. El estudiante demuestra el valor anterior, la regla aplicada, el valor resultante y el impacto sobre el análisis.
