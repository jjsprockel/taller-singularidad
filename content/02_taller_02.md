# Taller 2 Trabajo riguroso con chatbots y modelos de lenguaje

## Justificación

Pasar de conversaciones informales con un chatbot a interacciones reproducibles, verificables y seguras para tareas académicas.

## Resultados de aprendizaje

- Diseñar instrucciones con propósito, contexto, restricciones, formato y criterios de calidad.
- Usar iteración, crítica y comparación de respuestas sin delegar el juicio científico.
- Registrar prompts, archivos, versión o fecha, salida y decisión humana.
- Aplicar reglas de privacidad y verificación de afirmaciones.

## Contexto teórico

- Tokens, contexto, temperatura y variabilidad explicados de forma conceptual.
- Alucinación, sesgo, obediencia aparente, contaminación del contexto y exceso de confianza.
- Patrón de trabajo: definir, producir, comprobar, corregir y documentar.
- Uso del computador para trabajar con archivos, tablas y documentos bajo supervisión humana.

## Preparación

- Instalar o verificar acceso a una plataforma autorizada.
- Traer un texto corto, una tabla pública y una pregunta relacionada con el proyecto.
- Leer la política de datos del semillero.

## Actividad paso a paso

1. Resolver una tarea con un prompt espontáneo y conservar el resultado.
2. Reformular el prompt con propósito, contexto, datos, restricciones, formato y criterios de aceptación.
3. Solicitar al modelo una autocrítica y una lista de afirmaciones que necesitan fuente.
4. Verificar manualmente una muestra mínima de cinco afirmaciones o valores.
5. Comparar versiones mediante una rúbrica y redactar un prompt reutilizable.
6. Registrar qué se aceptó, qué se modificó y qué se descartó.

## Aplicación al proyecto

El estudiante debe aplicar la actividad al proyecto asignado y señalar con precisión qué parte elaboró de forma individual. Si el proyecto aún no dispone de datos o autorización, utilizará datos sintéticos, públicos o un caso de práctica. La entrega debe incluir la versión anterior, la nueva versión y una nota breve sobre las decisiones tomadas con apoyo de IA.

## Entregables

- Prompt reutilizable comentado
- Comparación antes y después
- Registro de verificación de cinco afirmaciones
- Bitácora de decisiones

## Lista de chequeo y KPI

- [ ] El prompt define resultado esperado y criterios de aceptación.
- [ ] Cinco afirmaciones están verificadas contra fuentes o datos.
- [ ] Ningún dato identificable se cargó en una plataforma no autorizada.
- [ ] La salida final muestra cambios humanos trazables.
- [ ] El estudiante puede explicar por qué rechazó al menos una sugerencia.

**Criterio de avance:** completar al menos 80 por ciento de la lista, sin incumplimientos de privacidad, referencias inventadas o pérdida de trazabilidad.

## Retroalimentación semanal

Demostración breve de un prompt. El grupo identifica ambigüedades, riesgos y verificaciones faltantes antes de revisar la calidad del texto final.
